# Ejemplos y juegos

Cada carpeta es un juego completo que se monta con `python3 scripts/build.py juegos/<nombre>`. Para empezar uno parecido: `scripts/nuevo-juego.sh <nombre> --desde <ejemplo>`. Cada uno lleva su `EJEMPLO.md` (qué demuestra, perillas, qué sustituir) y sus medidas.

| Ejemplo | Mecánica | Estado | Motor | Marca | Ficha |
|---|---|---|---|---|---|
| [quien-es-quien](quien-es-quien/) | Deducción con cartas y un robot que piensa en voz alta | en producción | no (anterior) | nothiring | [EJEMPLO.md](quien-es-quien/EJEMPLO.md) |
| [pistacho-imperium](pistacho-imperium/) | Territorios con dados sobre un mapa real, con premio | publicado, sin probar con personas | sí | Vergel (inventada) | [EJEMPLO.md](pistacho-imperium/EJEMPLO.md) |

Para subir otro juego que ya esté hecho: [docs/08-handoff-subir-juegos.md](../docs/08-handoff-subir-juegos.md). Cómo se organiza todo: [docs/07-repositorio.md](../docs/07-repositorio.md).
